Ever since I started building my first React components, I've been drawn to the part of software most people never see: the server quietly verifying a signature, the database schema deciding what's even possible on the frontend, the auth middleware standing between a request and the data it's asking for. That's usually where I end up spending most of my time on a project, even the ones that start as "just a frontend task."

My path here wasn't a straight line. I graduated in Electronics & Communication Engineering from Sir C.R. Reddy College of Engineering, Eluru, with a CGPA of 8.2, and along the way ended up guest-lecturing to a batch of 100+ students, which taught me almost as much about explaining things clearly as it did about the subject itself. But most of my actual hands-on hours over the past year have gone somewhere else entirely: full stack web development.

I spent four months as a Frontend Developer Intern at Expograph, building React components for a live Learning Management System and integrating REST APIs end to end, inside a real, existing codebase, on a real team schedule. That experience shaped how I think about code now: not "does it work on my machine," but "does it survive contact with other people's data, other people's bugs, and a deadline I didn't set."

Since then, I've been building projects that push past the usual portfolio CRUD app. **RazorLens** verifies every incoming Razorpay webhook with HMAC-SHA256 against a per-user secret, stores both valid and rejected events, and gives every user their own isolated, multi-tenant endpoint. **Reqora** is a real-time collaborative API-testing tool, built with secured, authenticated request execution from the ground up. Alongside those, I've shipped a real-time 1v1 study platform (**SkillDuel**), an infrastructure monitoring dashboard (**CloudPulse**), and a live client site for a financial advisory firm (**Finvis Associates**) that's actually in production today, not just a demo link.

I hold a **Gold Badge in SQL on HackerRank**, a **Silver Badge in Java**, and I'm certified in **Microsoft Excel** — evidence of the habit of actually finishing what I start, even the unglamorous parts. Right now I'm deepening TypeScript, Next.js, and the kind of backend concerns (testing, Docker, Redis) that separate a project that works from one that's genuinely production-ready.
